# Blinkit Power BI Analytics Dashboard

This repository contains an interactive **Power BI Dashboard (`blinkit.pbix`)** designed to analyze key business metrics, performance indicators, and data insights for Blinkit operations.

---

## 📊 Overview

The dashboard provides visual data analytics built directly within Microsoft Power BI. It leverages custom themes (including Microsoft Fluent 2 and Frontier) and tailored visualizations to give clear insights into operational data, trends, and key performance metrics.

### Key Features
* **Interactive Data Visualizations:** Dynamic filtering, category breakdowns, and performance trends.
* **Custom Styling:** Clean UI design utilizing Fluent 2 theme aesthetics.
* **Data Model:** Structured data relationships and calculated DAX metrics.

## 🚀 How to View & Use

1. **Download the File:** Click on `blinkit.pbix` in this repository and select **Download**.
2. **Install Power BI Desktop:** Ensure you have [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed on your machine.
3. **Open the Report:** Double-click `blinkit.pbix` to launch and interact with the full report, slice data, and explore measures.

---

## 🛠 Requirements

* **OS:** Windows 10 / 11 (required for Power BI Desktop)
* **Software:** Microsoft Power BI Desktop (Latest version recommended)
